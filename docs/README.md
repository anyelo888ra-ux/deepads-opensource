## Estado actual

DeepAds se encuentra en una etapa temprana. La interfaz pública y la documentación sirven como base para futuras APIs y servicios dinámicos.

## Principio importante

DeepAds no debe convertir la exposición en una garantía de posicionamiento. Las integraciones deben mantener sus propios criterios de calidad, relevancia y seguridad.
