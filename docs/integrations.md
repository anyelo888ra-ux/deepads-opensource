# Integraciones

DeepAds está pensado como una capa que otros proyectos pueden integrar.

## Motores de búsqueda

Un motor puede usar la señal de DeepAds como una señal pequeña y controlada de descubrimiento.

Ejemplo futuro:

```
Consulta
  ↓
Resultados relevantes
  ↓
Señales de calidad + otras señales
  ↓
Señal DeepAds limitada
  ↓
Resultados
```

DeepAds no debería reemplazar la relevancia del contenido.

## Tiendas de aplicaciones

Una tienda puede utilizar DeepAds para dar una pequeña oportunidad adicional de descubrimiento a aplicaciones que participen en campañas.

## Sitios web

Un sitio puede mostrar anuncios mediante un embed.

## Futuras integraciones

El proyecto puede proporcionar una API compatible para que implementaciones independientes puedan crear sus propios servicios.
