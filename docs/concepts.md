# Conceptos

## Campaña

Una campaña representa un anuncio o contenido promocionado que participa en DeepAds.

## Vista válida

Una vista válida es un evento que una implementación considera suficientemente real para contribuir al sistema de exposición.

La definición exacta depende de la implementación y debe documentarse públicamente.

## Exposición

La exposición representa una pequeña oportunidad adicional de descubrimiento dentro de un servicio compatible.

Regla propuesta para el prototipo:

**5 vistas válidas → +0,1% de exposición**

El valor es deliberadamente pequeño.

## Embed

El embed es el identificador/integración que permite colocar una campaña en un proyecto compatible.

Los embeds deben ser limitados y revocables. No deben contener secretos de servidor de alto privilegio.

## No pago por vista

DeepAds no define pagos monetarios por visualizar anuncios. La propuesta utiliza exposición dentro de servicios integrados.
