# Security Policy

## Objetivo

DeepAds busca ser **security-first y auditable**.

## Reportar problemas

Si encuentras una vulnerabilidad de seguridad, evita publicar detalles sensibles antes de que exista una corrección.

Abre un reporte privado mediante los mecanismos de seguridad disponibles en GitHub cuando estén habilitados para el repositorio.

## Reglas importantes

- Nunca incluyas API keys o secretos en issues públicos.
- No compartas embeds privados públicamente.
- No pruebes vulnerabilidades contra servicios de terceros sin autorización.
- Las pruebas deben realizarse sobre instalaciones propias o entornos autorizados.

## Alcance

Esta política corresponde al código de DeepAds. Las implementaciones independientes son responsables de sus propios despliegues y configuraciones.
