## v0.5 — Ads Creator + Demo

- Añadido `create.html` para preparar anuncios gratis en modo demo.
- Añadido selector local de imágenes y MP4.
- Añadida validación básica de URLs HTTP/HTTPS.
- Añadida interfaz preparada para verificación server-side.
- Añadido `ads-demo.html` con ejemplos visuales de anuncios.
- Añadido formato conceptual de embed para anuncios.
- Añadida documentación del flujo VirusTotal.
- Aclarado que la API key de VirusTotal debe permanecer en el backend.
- Aclarado que VirusTotal es una señal de seguridad y no una garantía absoluta.
- Añadida documentación sobre privacidad y límites de la API.
- Actualizado roadmap hacia v1.0.
